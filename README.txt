================================================================================
AI ไอปันยาอ่อน วิเคราะห์บอล - UEFA CHAMPIONS LEAGUE (UCL) 2026–27
================================================================================

เว็บไซต์สำหรับอ่านบทวิเคราะห์ฟุตบอล UEFA Champions League ฤดูกาล 2026–27 
รอบ League Phase (Matchday 4 of 8) นำเสนอข้อมูลจริงจากไฟล์ Ucl.txt 
ในรูปแบบ Static Website ที่สวยงาม ทันสมัย อ่านง่าย และมีข้อมูลสถิติเชิงลึกครบถ้วน

--------------------------------------------------------------------------------
1. รายการคู่แข่งขันในบทวิเคราะห์ (ทั้งหมด 9 คู่)
--------------------------------------------------------------------------------
โปรแกรมการแข่งขันคืนวันอังคารที่ 3 พฤศจิกายน 2026 ตามเวลาท้องถิ่นยุโรป 
ตรงกับเช้ามืดวันพุธที่ 4 พฤศจิกายน 2026 ตามเวลาประเทศไทย:

คู่แข่งขันกลุ่ม 00:45 น. (เวลาไทย):
- คู่ที่ 1: Galatasaray พบ VfB Stuttgart (Ali Sami Yen RAMS Park, อิสตันบูล)
- คู่ที่ 2: Shakhtar Donetsk พบ Sporting CP (Stamford Bridge, ลอนดอน - สนามกลาง)

คู่แข่งขันกลุ่ม 03:00 น. (เวลาไทย):
- คู่ที่ 3: Feyenoord พบ Inter Milan (De Kuip, ร็อตเตอร์ดัม)
- คู่ที่ 4: Bodø/Glimt พบ LOSC Lille (Aspmyra Stadion, โบโด)
- คู่ที่ 5: Atlético Madrid พบ Bayern Munich (Riyadh Air Metropolitano, มาดริด)
- คู่ที่ 6: Villarreal พบ Paris Saint-Germain (Estadio de la Cerámica, บิยาร์เรอัล)
- คู่ที่ 7: FC Barcelona พบ Aston Villa (Spotify Camp Nou, บาร์เซโลนา)
- คู่ที่ 8: Manchester United พบ AS Roma (Old Trafford, แมนเชสเตอร์)
- คู่ที่ 9: LASK Linz พบ Slovan Bratislava (Raiffeisen Arena, ลินซ์)

*(หมายเหตุ: คู่ Fenerbahçe พบ Liverpool ซึ่งแข่งขันในวันพฤหัสบดีที่ 5 พ.ย. เวลา 00:45 น. ตัดออกตามเงื่อนไขของ Ucl.txt)*

3. วิธีเปิดใช้งานเว็บไซต์
--------------------------------------------------------------------------------
เว็บไซต์นี้เป็น Static Website 100% ไม่จำเป็นต้องมี Backend หรือ Database

วิธีที่ 1 (ง่ายที่สุด):
- ดับเบิลคลิกที่ไฟล์ `index.html` เพื่อเปิดใช้งานบน Web Browser ใดก็ได้ 
  (Google Chrome, Microsoft Edge, Mozilla Firefox, Safari) 
  โดยสามารถเปิดอ่านแบบ Offline ได้ทันที

วิธีที่ 2 (ผ่าน Local Server):
- เปิดผ่านโปรแกรม Local Web Server เช่น VS Code Live Server หรือรันคำสั่ง:
  python -m http.server 8000
  จากนั้นเปิดเบราว์เซอร์ไปที่ http://localhost:8000

4. จุดเด่นและฟังก์ชันการใช้งาน
--------------------------------------------------------------------------------
1. หน้าแรก (Opening Page):
   - คำคมประจำบทวิเคราะห์: "ราคาที่น่าสนใจ ไม่ได้หมายถึงทีมที่แข็งแกร่งที่สุดเสมอไป แต่คือราคาที่สะท้อนโอกาสได้คุ้มค่าที่สุด"
   - ข้อมูลวันที่ เวลา และสถิติสรุปภาพรวม 9 คู่ 18 สโมสร
   - ปุ่มลัดเข้าสู่บทวิเคราะห์

2. หน้ารวมคู่แข่งขัน (Match Overview):
   - การ์ดคู่แข่งขัน Match Card ครบ 9 คู่ แสดงโลโก้ทีม เวลาเตะ สนาม สกอร์คาดการณ์ และตลาดเด่น
   - แถบตัวกรอง (Filter): ทั้งหมด, เตะ 00:45 น., เตะ 03:00 น., ความมั่นใจ 85%+, ความเสี่ยงต่ำ
   - ช่องค้นหา (Live Search): ค้นหาด้วยชื่อทีม ภาษาไทย หรือภาษาอังกฤษได้ทันที

3. หน้าอ่านบทวิเคราะห์เจาะลึก (Match Detail View):
   - จัดหมวดหมู่ 7 เสาหลักอย่างเป็นระเบียบ:
     1) ข้อมูลภาพรวมการแข่งขันและสถานการณ์ตารางคะแนน
     2) วิเคราะห์ฟอร์มการเล่น 5 นัดหลังสุด และสถิติ Head-to-Head
     3) สถิติเกมรุก-เกมรับเชิงลึก, Sofascore Team Ratings, โอกาสยิง
     4) ข่าวทีม ผู้เล่นบาดเจ็บ โทษแบน และไม่มีสิทธิ์ลงสนาม (อัปเดต 1–2 พ.ย. 2026)
     5) วิเคราะห์แท็กติก กุนซือ การขึ้นเกม เพรสซิ่ง จุดแข็ง และจุดอ่อน
     6) วิเคราะห์ราคาต่อรอง 1X2, Over/Under, BTTS และส่วนต่างความคุ้มค่า (Value Betting)
     7) การคัดเลือกและจัดอันดับตลาดเดิมพันที่น่าสนใจ (ตัวเลือกที่ 1, 2, 3), จุดแข็ง-จุดอ่อน และคะแนนความน่าเชื่อถือ

4. หมวดภาพรวมและการจัดอันดับ (Overall Rankings & Summary):
   - คู่ที่มีข้อมูลสนับสนุนมากที่สุด (อันดับ 1: Villarreal พบ PSG 88/100)
   - คู่ที่มีความได้เปรียบชัดเจนและราคาคุ้มค่าที่สุด (อันดับ 1: Bodø/Glimt พบ LOSC Lille @ 1.92)
   - คู่เด่น Over / Under 2.5
   - คู่เด่น BTTS (ทั้งสองทีมยิงประตู)
   - คู่ที่มีความเสี่ยงสูงและควรระวัง (Man Utd พบ Roma, Bayern Munich, Barcelona)
   - ตารางสรุป 9 คู่ Interactive Summary Table พร้อมปุ่มคลิกเปิดดูบทวิเคราะห์แต่ละคู่ได้ทันที

--------------------------------------------------------------------------------
5. แหล่งที่มาของข้อมูลและข้อจำกัด (Data Sources & Disclaimers)
--------------------------------------------------------------------------------
- แหล่งข้อมูลอ้างอิง: รวบรวมและตรวจสอบข้อมูลจริง ณ วันที่ 1–2 พฤศจิกายน 2026 จาก 
  Google Sports Data, Sofascore, Flashscore, Transfermarkt และ Oddslot
- ข้อจำกัดค่า xG: แหล่งข้อมูลสาธารณะก่อนเริ่มแข่งไม่ได้เปิดเผยค่า xG/xGA ดิบ จึงใช้สถิติประตูได้-เสียจริง,
  เรตติ้งเฉลี่ยของ Sofascore และสถิติการสร้างโอกาสยิงแทน
- ข้อจำกัดรายชื่อ 11 ตัวจริง: รายชื่ออย่างเป็นทางการจะประกาศก่อนแข่ง 1 ชั่วโมง จึงใช้ข้อมูลแกนหลักล่าสุด
  และบัญชีรายชื่อผู้เล่นบาดเจ็บ/ติดโทษแบนที่ยืนยันแล้ว
- ตลาด Asian Handicap และ Team Goals: แหล่งข้อมูลเปิดเผยราคาจริงเฉพาะตลาดหลัก (1X2, O/U 2.5, BTTS)
  ส่วนตลาดแฮนดิแคปนำเสนอในเชิงวิเคราะห์ความแข็งแกร่งและคำนวณ Fair Odds เทียบเคียง

คำเตือน:
เว็บไซต์นี้จัดทำขึ้นเพื่อการศึกษาและการวิเคราะห์ทางสถิติกีฬาเท่านั้น ไม่สนับสนุนการเล่นการพนัน 
ไม่มีระบบสมาชิกหรือรับฝากเงินใดๆ ทั้งสิ้น การวิเคราะห์เป็นการประเมินความน่าจะเป็นและเปรียบเทียบ
ความคุ้มค่าเชิงสถิติ ไม่สามารถรับประกันผลการแข่งขันได้
